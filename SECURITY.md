# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 1.0.x-canonical | ✅ |

## Reporting a Vulnerability

If you discover a security vulnerability in the ALETHEIA19 diagnostic engines or emulators, please report it responsibly:

1. **Do NOT open a public issue.**
2. Email: contact@aletheia19.org
3. Include: description, reproduction steps, and potential impact.
4. Expected response time: 72 hours.

## Scope

This policy covers the open-core components of this repository (`demo_sensor.py`, `ontology.yaml`, `docs/`). Private diagnostic engines (`00_ENGINES/`, `Enclosure/`) are not part of the public distribution.
