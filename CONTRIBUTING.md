# Contributing to ALETHEIA19

Thank you for your interest in contributing to the FASCIA Protocol.

## How to Contribute

### Proposing New Isomorphisms
Use the [Propose Isomorphism](../../issues/new?template=propose_isomorphism.md) issue template to submit a new cognitive isomorphism for review against the 27,188 invariants registry.

### Reporting a Chimera (False Signal)
Use the [Report Chimera](../../issues/new?template=report_chimera.md) issue template to flag a suspected false positive or taxonomic misclassification.

### Code Contributions
1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-contribution`)
3. Ensure `demo_sensor.py` runs without errors
4. Submit a Pull Request using the provided template

## Metrological Integrity (Fa Rule)
All contributions must comply with the arithmetic floor verification rule:
- No geometric invariants without arithmetic validation
- No ad-hoc metrics without canonical taxonomy mapping (D1–D7)
- No unverified numerical claims
